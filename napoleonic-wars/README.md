# Napoleonic Wars Strategy Game

Пошаговая стратегия в сеттинге Наполеоновских войн (конец XVIII — начало XIX века).

## Требования

- Java JDK 11 или выше
- Компилятор javac

## Структура проекта

```
napoleonic-wars/
├── config/                 # Конфигурационные файлы
│   ├── countries.json      # Описание стран
│   └── regiments_type.json # Типы полков
├── src/                    # Исходный код
│   ├── Main.java           # Точка входа (консольная версия)
│   ├── config/             # Загрузчик конфигурации и JSON парсер
│   ├── map/                # Карта, гексы, регионы, города
│   ├── army/               # Армии и полки
│   ├── battle/             # Тактические сражения
│   ├── game/               # Игровая логика
│   └── ui/                 # Графический интерфейс (Swing)
├── out/                    # Скомпилированные классы
├── run.sh                  # Скрипт компиляции
└── README.md               # Этот файл
```

## Компиляция

```bash
./run.sh
```

Или вручную:

```bash
mkdir -p out
javac -d out src/config/*.java src/map/*.java src/army/*.java src/battle/*.java src/game/*.java src/Main.java
javac -cp out -d out src/ui/*.java
```

## Запуск

### Консольная версия (демонстрация)
```bash
java -cp out Main
```

### Графическая версия (GUI)
```bash
java -cp out ui.GameWindow
```

## Управление в GUI

- **Клик на гекс** - выбрать гекс и показать информацию
- **Кнопка "Переместить"** - переместить выбранную армию
- **Кнопка "Конец хода"** - завершить ход текущего игрока

## Особенности игры

### Глобальная карта
- Гексагональная сетка (hex grid)
- Различные типы местности: равнина, лес, горы, холмы, река, болото, дорога, город
- Регионы принадлежат разным странам
- Города позволяют нанимать новые полки

### Армии и полки
- До 20 полков в армии
- 7 типов полков: линейная пехота, лёгкая пехота, гренадёры, кирасиры, драгуны, уланы, артиллерия
- Система опыта для полков
- Инвентарь со снаряжением (оружие, флаг, бонусы, лошади, пушки)

### Боевая система
- Пошаговые тактические сражения на отдельной карте
- Учёт местности при расчёте урона
- Артиллерия требует перезарядки

### Страны
- Франция (Наполеон Бонапарт)
- Великобритания (Герцог Веллингтон)
- Австрия (Эрцгерцог Карл)
- Пруссия (Гебхард фон Блюхер)
- Россия (Михаил Кутузов)
